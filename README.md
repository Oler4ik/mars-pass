# 🚀 Mars Pass
Eine Webseite für eine fiktive Reise zum Mars. Das Projekt wurde im Rahmen des Kurses „160 Web-Entwicklung“ mit HTML, CSS und JavaScript erstellt.
 
Funktionen:
 
- Startseite: Vorstellung der Marsreise
- Bildergalerie: Bilder mit Navigation, Beschreibung und Bildzähler
- Anfrageformular: Eingabe von Kontaktdaten mit Prüfung der Eingaben
- Responsive Design: Anpassung des Layouts an Desktop und Smartphone
- CSS-Animationen: Visuelle Effekte für eine lebendige Gestaltung
 
Verwendete Technologien:
 
- HTML: Struktur und Inhalte
- CSS: Gestaltung, Flexbox, Media Queries und Animationen
- JavaScript: Interaktive Funktionen und DOM-Manipulation
 
Projekt starten:
 
1. Die Datei Index_MARS.html im Browser öffnen.
 
Es ist keine Installation erforderlich.
 
Lernziele:
 
Ziel des Projekts war es, eine zusammenhängende Webseite selbstständig zu gestalten und grundlegende Kenntnisse in HTML, CSS und JavaScript praktisch anzuwenden. Schwerpunkte waren responsives Design, Benutzerinteraktion und die Verarbeitung von Formulareingaben.
 
Hinweis
 
Mars Pass ist ein Lernprojekt. Die angebotene Marsreise ist fiktiv; es können keine echten Reisen gebucht werden.
